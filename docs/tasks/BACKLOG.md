## 3. Protocol for Creating Future Tasks

When initiating a new feature or bugfix task:

1. **Assign a Unique Task ID**: Use format `TASK-[NUMBER]` (e.g. `TASK-09`) or `FIX-[NUMBER]`.
2. **Create Task Specification**: Create `docs/tasks/TASK-XXX/SPEC.md` containing:
   - Objective & user rationale
   - Current behavior & supporting source evidence
   - Exact scope and strictly forbidden changes
   - Implementation plan & test verification criteria
3. **Create Task Handoff**: Create `docs/tasks/TASK-XXX/HANDOFF.md` containing:
   - Self-contained instructions for fresh session agents
   - Links to canonical project knowledge documents
4. **Update Backlog**: Add the new task to the table above with status `PLANNED` or `IMPLEMENTED`.
5. **Post-Implementation Documentation**: Follow the maintenance contract in `docs/project-knowledge/README.md`.
